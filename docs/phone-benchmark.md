# 팀원 폰 YOLO 검출 속도 측정 방법

목적: **가장 느린 폰이 50분 경기를 몇 분에 처리하는지** 알아서 최저 지원 기종, 모델 크기, 느린 폰 대책을 정합니다.

도구: Ultralytics 공식 Flutter 플러그인의 예제 앱(`example/`). 실시간 카메라 화면에 **1프레임 처리 시간(ms)과 FPS**를 표시합니다. 표시되는 ms는 플러그인의 `processingTimeMs`(모델 추론 + 결과 변환) 값입니다.
저장소: https://github.com/ultralytics/yolo-flutter-app

## 1. 준비 (앱을 빌드할 사람 1명)

| 항목 | 요구 사항 |
|---|---|
| Flutter | 3.32.1 이상 (Dart 3.8.1 이상) |
| 안드로이드 | Android Studio, 폰은 Android 6.0(API 23) 이상 |
| 아이폰 | **Mac + Xcode** 필요, 폰은 iOS 13 이상 (15 이상 권장) |

```bash
# Flutter 설치 확인
flutter doctor

# 예제 앱 받기
git clone https://github.com/ultralytics/yolo-flutter-app.git
cd yolo-flutter-app/example
flutter pub get
```

모델 파일은 앱이 처음 실행될 때 자동으로 내려받습니다. 첫 실행은 **와이파이에서** 하세요.

## 2. 팀원 폰에 설치

### 안드로이드: APK 하나 만들어서 나눠 주기 (가장 쉬움)
```bash
cd yolo-flutter-app/example
flutter build apk --release
# 결과: build/app/outputs/flutter-apk/app-release.apk
```
- 이 APK 파일을 카톡 등으로 팀원에게 보냅니다.
- 팀원은 파일을 열고 **"출처를 알 수 없는 앱 설치 허용"**을 켠 뒤 설치합니다.
- PC에 폰을 직접 연결해서 설치하려면: 폰에서 **개발자 옵션 → USB 디버깅**을 켜고 `flutter run --release`

### 아이폰: Mac에 한 대씩 연결해서 설치
```bash
cd yolo-flutter-app/example/ios && pod install --repo-update && cd ..
open ios/Runner.xcworkspace        # Xcode가 열림
```
1. Xcode에서 **Runner → Signing & Capabilities → Team**에 본인 Apple ID를 선택합니다. 무료 계정이면 "Personal Team"이 나옵니다.
2. Bundle Identifier를 겹치지 않게 바꿉니다. 예: `com.본인이름.yolotest`
3. 아이폰을 USB로 연결하고 `flutter run --release`
4. 처음 실행할 때는 아이폰에서 **설정 → 일반 → VPN 및 기기 관리**로 가서 개발자를 신뢰해 줘야 합니다.
5. 무료 Apple ID로 설치한 앱은 **7일 뒤 실행이 안 됩니다.** 측정은 그 안에 끝내세요.

반드시 **`--release`**로 설치하세요. 디버그 빌드는 느리게 나와서 측정값이 틀어집니다.

## 3. 측정 순서 (폰마다 약 10분)

1. **조건 맞추기**
   - 충전기 연결, 절전 모드 끄기
   - 다른 앱은 모두 종료
   - 폰이 차가운 상태에서 시작
2. 예제 앱을 실행합니다. 모델을 고를 수 있으면 **가장 작은 모델(n)**부터 측정합니다.
3. 카메라를 **사람이 여럿 보이는 장면**에 고정합니다. 모니터에 풋살 경기 영상을 띄워 놓고 찍으면 됩니다.
4. **1분 후** 화면의 ms와 FPS를 기록합니다. 숫자가 흔들리면 대략 가운데 값을 적습니다.
5. 그대로 **5분 더** 켜 두고 다시 기록합니다. 발열 때문에 느려지는지 보기 위해서입니다.
6. 더 큰 모델(s)도 고를 수 있으면 폰을 식힌 뒤 2~5를 반복합니다.

## 5. 50분 경기 처리 시간으로 바꾸기

경기 후 처리에서는 녹화 파일을 읽는 시간(프레임당 약 5~10ms)이 더해집니다. 초당 10번 검출하면 50분 경기는 약 30,000프레임입니다.

**처리 시간(분) ≈ 30,000 × (5분 후 ms + 7) ÷ 60,000**

| 5분 후 ms | 50분 경기 처리 시간 | 판단 |
|---|---|---|
| 10ms | 약 8분 | 여유 있음. 화면을 나눠 검출하는 타일링(×2~4)도 가능 |
| 30ms | 약 18분 | 괜찮음 |
| 100ms | 약 54분 | 검출 간격을 절반(초당 5번)으로 줄이면 약 27분 |
| 250ms | 약 2시간 10분 | 빠른 폰이 대신 처리하거나 밤새 처리 |

먼 쪽 선수를 잘 잡으려고 화면을 2~4조각으로 나눠 검출하면(타일링) 시간도 2~4배 늘어납니다.

## 6. 측정 후 정할 것
- **최저 지원 기종:** 50분 경기를 30~40분 안에 처리할 수 있는 기종을 기준으로 잡는 것을 권장합니다.
- **모델 크기:** 가장 느린 폰에서도 s 모델이 위 기준 안에 들어오면 s, 아니면 n
- **느린 폰 대책:** 검출 간격 자동 조정, 빠른 폰이 두 영상 모두 처리, 밤새 처리
