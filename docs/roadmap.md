# 로드맵 (2026년 10~11월, 1차)

## 방향: 서버 없이 휴대폰에서 모두 처리

서버 비용을 없애기 위해 **촬영부터 분석, 결과 확인까지 폰 2대 안에서 끝냅니다.** 구조는 [시스템 구조](architecture.md)에 있습니다.

| | 트랙 A: 분석 품질 (PC) | 트랙 B: 앱 (폰) |
|---|---|---|
| 목적 | 실제 영상으로 **정답 결과**를 만들고 모델을 고름 | 같은 처리를 **폰 안에서** 돌림 |
| 도구 | `src/futsal/` Python 코드, 개발용 PC 도구(`server/`) | Flutter, Ultralytics YOLO 플러그인 |
| 산출물 | 폰용 검출 모델(CoreML / TFLite), 정확도 기준값 | 촬영 → 검출 → 병합·추적 → 결과 화면 앱 |

트랙 A가 "이렇게 하면 이 정도 정확도"를 PC에서 먼저 확인하고, 트랙 B가 같은 결과를 폰에서 재현합니다. 두 트랙은 같은 파일 형식(`det.json`, `calib.json`, `tracks.json`)을 써서 서로 결과를 비교할 수 있습니다.

## 지금 된 것 (이 저장소)
- FIFA 규격 코트, 기준점 29개 탭 보정, 두 카메라 병합, 경기장 위 추적, 칼만 스무딩 지표 (Python 기준 구현)
- 배치·화각 시뮬레이터와 결과 문서
- 개발용 PC 도구(업로드, 보정, 분석, 결과)와 2D 지도 웹 뷰어
- 합성 영상으로 전체 흐름 테스트

## 주차별 계획

| 주 | 트랙 A (PC, 분석 품질) | 트랙 B (앱) | 완료 기준 |
|---|---|---|---|
| **1주 (10/7~10/12)** | **실제 구장 테스트 촬영** (추천 배치, 2대, 10~15분, 라인 실측, 콘 위치 기록) | Flutter 환경 세팅, Ultralytics YOLO 플러그인 예제를 **팀원 폰 전부에서** 실행 → 기종별 1프레임 검출 시간 측정 | 실제 영상 2개 + 기종별 검출 속도표 |
| 2주 (10/13~10/19) | 실제 영상에 YOLO11n / 11s 사전학습 모델 실행 → 먼 선수 놓치는 비율, 타일링 효과 비교 | 촬영 화면 (설치 안내 오버레이) + 녹화 + 녹화 파일에서 프레임 읽어 검출 → `det.json` 저장 | 폰이 만든 `det.json`을 PC 결과와 비교 |
| 3주 (10/20~10/26) | 실제 영상 끝까지 → 2D 지도. **콘 위치로 정확도 측정.** 라벨링 시작 (수백 장) | 보정 화면 (정지 화면 위 기준점 탭) + QR 짝짓기 + 시계 맞추기 | 폰 2대의 `det.json` + `calib.json`이 한 폰에 모임 |
| 4주 (10/27~11/2) | 파인튜닝 → CoreML / TFLite로 변환, 조끼 색 팀 구분 | 분석 코어 Dart 이식 (좌표 변환, 병합, 추적, 지표). Python과 같은 입력 → 같은 출력 확인 | 폰에서 `tracks.json` 생성 |
| 5~6주 (11/3~11/16) | ID 안정화, 정확도·처리 시간 평가 | 결과 화면 (2D 지도, 히트맵, 기록), 결과 이미지 공유, 느린 폰 대책 (검출 간격 자동 조정) | 실제 경기를 폰만으로 처리 |
| 7~8주 (11/17~11/30) | 평가 정리, 발표 자료 | 실제 경기 2~3회 시연, 안정화 | 발표 |

## 이번 주에 할 일 (가장 중요)

1. **테스트 촬영** ([촬영 가이드](capture-guide.md) 그대로)
   - 대각선 코너 2곳, 삼각대 2m 이상, 1x, 상대 폰이 화면 가로 약 57% 지점에 오게
   - 10~15분, 시작과 끝에 손뼉
   - 콘 5개 정도를 놓고 줄자로 좌표 기록, 사람이 그 위에 5초씩 서 있기
   - 구장 라인 크기 실측, 삼각대 위치·높이 기록
2. **팀원 폰 전부에서 검출 속도 측정**: [측정 방법](phone-benchmark.md) 그대로. **최저 사양 기종이 몇 분 걸리는지가 설계를 정합니다.**
3. **개발 환경**: `pip install -e ".[server,sim,dev]"` → `pytest`, Flutter SDK 설치
4. **역할 분담 (예시)**
   - 비전 2명: 실제 영상 검출 품질, 파인튜닝, 모델 변환, 팀 구분 (트랙 A)
   - 앱 2명: 촬영·검출 / 보정·짝짓기·분석 코어 이식·결과 화면 (트랙 B)

## 결정해야 할 것
- 최저 지원 기종 (검출 속도 측정 결과로 정함)
- 검출 모델 크기: YOLO11n(빠름) / YOLO11s(정확), 타일링 사용 여부
- 결과 공유 방식: 이미지만 / 파일 / 무료 클라우드 링크
- 평가 지표: 위치 오차(콘 기준), 선수별 ID 유지율, 기종별 처리 시간
