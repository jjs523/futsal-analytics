| | 트랙 A: 녹화 후 업로드 | 트랙 B: 자체 앱 + 분할 업로드 |
|---|---|---|
| 목적 | **분석 품질 확보** (발표의 핵심 결과물) | **사용 편의성** (경기 직후 결과, 촬영 안내) |

## 이번 주에 할 일 (가장 중요)

1. **테스트 촬영** ([촬영 가이드](capture-guide.md) 그대로)
   - 대각선 코너 2곳, 삼각대 2m 이상, 1x, 상대 폰이 화면 가운데에서 약간 오른쪽
   - 10~15분, 시작과 끝에 손뼉
   - 콘 5개 정도를 정해진 위치에 놓고 줄자로 좌표 기록, 사람이 그 위에 5초씩 서 있기
   - 구장 라인 크기 실측, 삼각대 위치·높이 기록
2. **개발 환경**: 팀원 모두 `pip install -e ".[server,sim,dev]"` → `pytest` → `uvicorn server.app.main:app` → 뷰어에서 데모 경기 확인
3. **역할 분담** (예시)
   - 비전 2명: 검출·팀 구분·ID 안정화 (`src/futsal/pipeline/`)
   - 서버·웹 1명: 보정 화면 UI, 뷰어 기능 (`server/`, `web/`)
   - 앱 1명: 트랙 B 촬영 앱
4. 실제 영상이 생기면 `server/app/worker.py`의 검출기를 YOLO로 두고 업로드 → 보정 → 분석을 한 번 끝까지 돌려 보기
