# 풋살 분석 프로젝트 정리 (2026-10-07)

> 일반 휴대폰 2대로 풋살 경기를 찍어서 선수 위치를 2D 지도에 띄우고, 이동거리·속도·히트맵을 계산한다.
> **서버 비용을 없애기 위해 분석까지 휴대폰에서 모두 처리한다.**
> 코드와 상세 문서: GitHub `jjs523/futsal-analytics`

## 1. 지금까지 정한 것

| 주제 | 결정 | 근거 |
|---|---|---|
| 카메라 | 일반 휴대폰 2대 + 삼각대 | 누구나 쓸 수 있게 |
| 위치 | **대각선 두 코너**, 라인 밖 1~1.5m (펜스 안쪽) | 코트 둘레 모든 위치를 전수 탐색한 결과 1등 |
| 높이 | **2m 이상** | 1.5m면 가까운 선수 머리가 잘리고 겹침 증가 |
| 렌즈 | **1x 기본**, 0.5x는 선택 | 1x는 모든 폰에 있음 |
| 방향 | 마주보기에서 왼쪽으로 약 5° → 상대 폰이 화면 가로 **약 57%** 지점 | 두 대가 함께 보는 영역 74% → 80% |
| 펜스·그물 | 펜스 안쪽 런오프에 설치 (밖이면 렌즈를 그물 구멍에 붙이기) | 그물에서 떨어지면 격자가 찍힘 |
| **처리 위치** | **서버 없이 휴대폰에서 모두 처리** | 서버 비용(GPU·저장·업로드) 0 |
| 처리 시점 | 경기 중에는 녹화만, **경기 후 충전하면서 분석** | 녹화와 분석을 같이 하면 발열로 녹화가 끊길 수 있음 |
| 앱 | **Flutter** (아이폰·안드로이드 공통) + Ultralytics YOLO 공식 플러그인 | 팀원 폰이 섞여 있어도 한 코드 |
| 결과 공유 | 결과 이미지·파일을 카톡으로 (선택: 무료 클라우드 링크) | 서버 비용 0 |

## 2. 폰에서 다 되나?

| 단계 | 어디서 | 무게 |
|---|---|---|
| 촬영 안내, 녹화, QR 짝짓기·시계 맞추기 | 각 폰 | 가벼움 |
| **선수 검출 (YOLO)** | 각 폰, 경기 후 | **무거움**: 폰 성능에 따라 5분~2시간 |
| 보정 (기준점 탭) | 각 폰 | 가벼움 |
| 검출 결과 모으기 (수 MB) | 폰 2 → 폰 1 | 같은 와이파이·핫스팟 |
| 좌표 변환, 두 카메라 병합, 추적, 기록 계산 | 폰 1 | 가벼움 (수 초~수십 초) |
| 결과 화면·공유 | 폰 1 | 가벼움 |

→ **운영에 필요한 처리는 모두 폰에서 됩니다.** 모델 학습·변환만 개발 단계에서 PC나 무료 Colab으로 한 번 합니다.

### 50분 경기 검출 시간 (예상, 실제 폰에서 측정 필요)

| 폰 | 50분 경기 |
|---|---|
| 최신 플래그십 (NPU) | 약 5~10분 |
| 중급형 | 약 20~40분 |
| 보급형 (CPU만) | 약 1.5~2.5시간 |

느린 폰 대책: 검출 간격 줄이기(시간 절반), 빠른 폰이 두 영상 모두 처리, 밤새 충전하며 처리

## 3. 시뮬레이션 핵심 숫자 (FIFA 규격 40×20m, 1080p, 삼각대 2m)

| 항목 | 화각 좁은 폰 (아이폰 기본형 67°) | 화각 넓은 폰 (갤럭시 S26 74°) |
|---|---|---|
| 안 보이는 구역 | 0m² | 0m² |
| 두 대 모두 보는 영역 | 80% | 84% |
| 프레임당 위치 오차 중앙값 | 0.29m | 0.32m |
| 이동거리 오차 (스무딩 후) | 필드 선수 1% 이내, 골키퍼 +10% | 동일 |

- 약점: 카메라가 없는 두 코너(골대 앞 일부)는 먼 폰 하나만 봄 → 오차 크고 가려지면 못 봄
- 0.5x 광각이면 두 대가 코트 100%를 함께 봄

## 4. 구조

```
폰 1: 녹화 → (경기 후) 검출 ─────────────────┐
폰 2: 녹화 → (경기 후) 검출 → 결과 수 MB 전송 ─┤
                                            ▼
            폰 1: 보정 → 병합 → 추적 → 기록 → 2D 지도·히트맵 → 카톡 공유
```

저장소: Python 기준 구현(코트·보정·병합·지표, 앱으로 옮길 원본이자 정답 비교용), 시뮬레이터, 개발용 PC 도구, 2D 지도 뷰어, 테스트 20개. 앱(Flutter)은 다음 단계.
